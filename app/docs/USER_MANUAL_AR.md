# دليل المستخدم — أوتو كير برو

> مكتوب للعاملين في الورشة. كل خطوة بالأيقونة اللي هتشوفها على الشاشة. لو علقت في أي حتة، دوس **الرئيسية** فوق على اليمين وابدأ من الأول — مفيش حاجة بتضيع.

## ١) الدخول
اكتب **اسم المستخدم** و**كلمة المرور** واضغط **دخول**. لو نسيت كلمة المرور اطلب من المدير يغيّرها. (بعد دقائق من عدم الاستخدام النظام بيطلب الدخول تاني — ده للأمان.)
تقدر تغيّر كلمة المرور بنفسك: دوس على اسمك فوق → **تغيير كلمة المرور**.

## ٢) الشاشة الرئيسية
مربعات كبيرة بأيقونة واسم. بتشوف بس اللي يخص شغلك (الاستقبال، الفني، المدير… كل واحد له مربعاته).

| المربع | يعمل إيه |
|---|---|
| 📋 **استقبال عربية** | استلام عربية جديدة وفتح أمر صيانة |
| 🔨 **متابعة التصليح** | لوحة فيها كل العربيات اللي في الورشة دلوقتي |
| 🔍 **بحث عن عربية** | ابحث برقم اللوحة أو اسم العميل أو الموبايل أو رقم الأمر أو رقم الفاتورة أو رقم القطعة |
| 🚗 **العربيات / تسجيل عربية جديدة** | بيانات العربية وتاريخها |
| 👥 **العملاء / عميل جديد** | بيانات العملاء |
| 📦 **قطع الغيار** | الموردين والبحث عن قطعة |
| 🧾 **الفواتير** · 💰 **المصروفات** · 📈 **الحسابات** | للمحاسب والمدير |
| 🔔 **تذكيرات الصيانة** | عربيات حان موعد صيانتها |
| 📊 **التقارير** | كل التقارير + Excel وطباعة |

## ٣) استقبال عربية (٥ خطوات)
1. **العميل:** اكتب اسمه أو موبايله واختاره. مش موجود؟ دوس **عميل جديد** (لو فيه عميل مشابه هيحذرك).
2. **العربية:** اختار عربيته من القايمة أو **عربية جديدة**.
3. **حالة العربية:** اكتب قراءة العداد، اختار مستوى البنزين، وعلّم كل نقطة **سليم** أو **فيه عيب** (واكتب العيب). دوس 📷 لتصوير العيب. ممكن كمان تدوس على مكان العيب في **رسم العربية** وتختار نوعه (طعجة، خدش، صدأ، شرخ، كسر)، وزرار **الكل سليم** بيعلّم باقي النقاط سليمة. علّم **لمبات التابلوه** المضيئة. في صفحة العربية بيظهر فوق **شريط صحة العربية** (مع الأسباب) ورسم تطور العداد وأول صورة، وفي الفحص زرار **الكل سليم** وألوان أخضر/أصفر/أحمر.
4. **الشكوى:** دوس على الأيقونات (فرامل، زيت، تكييف…) واكتب تفاصيل لو محتاج. حدد الفني ولو فيه متعلقات جوه العربية.
5. **تأكيد:** راجع الملخص ودوس **حفظ وفتح أمر الصيانة**. هتظهر ورقة **إيصال الاستلام** — اطبعها (🖨) وخلّي العميل يمضي.
- الأزرار الكبيرة: **التالي / السابق / إلغاء**. البيانات اللي كتبتها **بتتحفظ تلقائياً** حتى لو قفلت الصفحة (الصور لا — صوّرها تاني).
- لو العربية دي عندها أمر مفتوح بالفعل، النظام مش هيسمح باستلامها مرتين.

## ٤) أمر الصيانة (من لوحة المتابعة دوس على العربية)
- **حالة الأمر:** بتتحدث تلقائياً مع تعيين الفني وتسجيل الفحص وإعداد وإرسال عرض السعر وموافقة العميل، وكمان مع تقدم الإصلاح ووصول وتركيب قطع الغيار. لما كل الأعمال تخلص والقطع تتركب، الحالة تبقى **فحص الجودة**؛ **جاهز للتسليم** بتظهر بعد اعتماد الجودة. لو ضفت شغل جديد بعد الجاهزية، الأمر يرجع للإصلاح. تقدر تضغط على حالة لتعديلها يدوياً، وتفضل لحد تسجيل خطوة شغل جديدة تستدعي تغييرها. كل انتقال بيتسجل مع سببه، والصفحة بتراجع التحديثات كل ٣٠ ثانية. الإلغاء بيطلب سبب والتسليم له تأكيده المنفصل.
- **الفنيين:** أضف أكتر من فني.
- **عمليات الصيانة:** اختار الفئة بالأيقونة → اختار من القايمة الجاهزة (مثلاً «تغيير فحمات فرامل أمامية») أو اكتب → الساعات وسعر الساعة (لو سبته فاضي بيستخدم سعر الإعدادات). الفني بيدوس **ابدأ** ثم **خلصت**.
- **قطع الغيار:** سجّل القطعة اللي اشتريتها من برة (الاسم، الماركة، رقم القطعة، المورد، فاتورة المورد، الكمية، سعر الشراء والبيع، الضمان). بعدين **تم الشراء → وصلت الورشة → تم التركيب** (واختار مين ركّبها). لو رجّعت قطعة دوس **مرتجع**. النظام بيحذرك لو سجّلت نفس القطعة بنفس فاتورة المورد مرتين.
- **الفحص:** اختار نوع الفحص وعلّم كل بند (سليم / يحتاج انتباه / حرج / لا ينطبق).
- **📷 الصور والمستندات:** صوّر أو أضف ملف PDF (فاتورة المورد مثلاً).

## ٥) عرض السعر وموافقة العميل
**عروض الأسعار ← عرض سعر جديد** (بيتعبّى من الأعمال والقطع) ← عدّل البنود/الخصم/الضريبة ← **تم إرسال العرض للعميل**. لما العميل يرد: علّم على البنود، اختار **موافق** أو **رفض**، واكتب **إزاي وافق** (واتساب، تليفون، ورقة…) و**الدليل**. من غير دليل النظام مش هيسجّل الموافقة.

## ٦) الفاتورة والدفع
**الفواتير والدفع ← إنشاء فاتورة** ← راجع ← **إصدار الفاتورة** (بعدها مفيش تعديل؛ التصحيح بإشعار دائن). **تسجيل دفعة** بأي مبلغ (جزئي أو كامل) — لو دوست مرتين بالغلط بتتسجل مرة واحدة. **عربون** قبل الفاتورة بيتحسب عليها لما تتصدر.

## ٧) فحص الجودة والتسليم
المسؤول (المدير) بيعلّم **راجعت الأعمال / راجعت القطع / جرّبت العربية** ويدوس **اجتاز الفحص** (أو **رفض** وبيرجع التصليح). في **تسليم العربية** النظام بيعرض اللي ناقص بالأحمر (عملية لم تنتهِ، قطعة لم تُركّب، فحص جودة، فاتورة، مبلغ متبقي). لما يبقى الكل أخضر اكتب العداد واسم المستلم ودوس **تسليم العربية** ثم اطبع **تقرير التسليم**. لو فيه نقص، المدير بس يقدر يسلّم باستثناء بسبب مكتوب، وده بيتسجل.

## ٨) تاريخ العربية
افتح العربية (🔍 بحث ← العربية): تلاقي **تاريخ العربية** من الأحدث للأقدم، دوس على أي زيارة تشوف كل تفاصيلها (القطع، الفني، الضمان، الفاتورة، الصور). فلتر بنوع الصيانة أو العداد. 🖨 للطباعة. تاريخ العربية **ما بيتمسحش** حتى لو اتغيّر المالك أو اللوحة — النظام بيحتفظ بالملاك واللوحات السابقة. فيه كمان **QR** تفتح بيه صفحة العربية (بتطلب تسجيل دخول).

## ٩) الضمان والتذكيرات
- الضمان بيتسجل أوتوماتيك لما تركّب قطعة لها فترة ضمان، وتقدر تضيف ضمان عمالة. مطالبة الضمان: **تسجيل مطالبة ضمان** (والمدير بيبت فيها).
- بعد التسليم النظام بيعمل **تذكيرات** (مثلاً تغيير الزيت بعد ٦ شهور أو ٥٠٠٠ كم). افتح **تذكيرات الصيانة** واتصل بالعميل.

## ١٠) نصائح وأخطاء شائعة
- رسالة حمراء = اقرأها، فيها السبب بالعربي بسيط. 
- **لا تقفل الصفحة أثناء الحفظ.** لو ظهر «تم تعديل السجل من مستخدم آخر» حدّث الصفحة وكرر.
- الألوان لوحدها مش كفاية: كل حالة معاها أيقونة وكلمة (✔ جاهز، ⏳ انتظار، ✖ مشكلة).
- لو شاشة بيضاء أو «النظام تحت الصيانة»: المدير بيعمل استعادة نسخة احتياطية، استنى دقائق وحدّث.
